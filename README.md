# BID QUEST — 나라장터 입찰 배틀

2026 조달청 AI 게임·콘텐츠 공모전 AI 게임 부문 출품작.
조달 공고(나라장터 입찰)를 소재로 한 로그라이크 카드 배틀 웹 게임.

## 실행 방법

- **오프라인(ZIP 제출본)**: 압축 해제 후 `index.html` 더블클릭. 설치·인터넷 불필요.
- **개발 서버**: `node server.mjs` 후 http://localhost:5173
- **웹 배포**: GitHub Pages (저장소 루트의 `index.html`, ES 모듈 버전)

## 조작

- 카드 클릭 = 선택/해제 → `선택 카드 사용` / `교체`(최대 2장)
- `입찰 제출` = 경쟁사 점수 공개 및 낙찰 판정
- `AI 힌트` = 게임당 3회, 최적 카드 추천
- 모바일: 터치 동일, 핸드 좌우 스크롤

## 룰 요약

- 8개 조달 공고(라운드), 라이프 3. 라운드당 제출 4회·교체 2회, 핸드 6장.
- 입찰서 = 입찰가 + 품질 + 정책 태그. 점수 = 가격점수×가격가중치 + 품질점수×품질가중치 + 정책가점.
- 적격 조건: 필수 태그 충족, 예산 이내, 낙찰하한율(예산의 80%) 이상. 하한율 미만 인하 불가.
- 필수 태그 인증서는 시작 핸드에 보장. 라운드 사이 카드 보상 드래프트.
- 경쟁사 3곳 점수 공개 배틀.담합 제보 카드로 경쟁사 1곳 실격 처리 가능.

## 정책 반영 요소 (게임 메커닉으로 구현)

- 나라장터 공고·입찰·낙찰하한율·적격 심사
- 혁신제품 / 중소기업 / 친환경 / 사회적경제 / 장애인기업 / 지역업체 인증 태그
- 공고별 가격·품질 가중치(종합심사낙찰제 모티브), 정책가점 콤보
- AI 경쟁분석(입찰 정보 공개), 담합 제보(부정당업자 제재 모티브)

## 기술

- Vanilla JS ES 모듈 + esbuild 단일 파일 번들(오프라인용), 빌드 도구 없음
- 2D Canvas 파티클 FX, 인라인 SVG 마스코트(오리지널 캐릭터: 비드·호비)
- WebAudio 절차 생성 SFX/BGM (외부 음원 없음)
- Press Start 2P 폰트 (SIL OFL, `assets/fonts/OFL.txt`) — 레트로 포인트 악센트

## AI 활용 고지

기획·코드·밸런스 시뮬레이션: 생성형 AI 코딩 에이전트(Qoder) 활용.
이미지·음원·폰트 등 외부 생성 에셋 미사용(폰트는 OFL 라이선스 폰트 벤더링).

## 개발 도구

- `node sim.mjs` : 밸런스 시뮬레이션(300게임)
- `node shot.mjs` : 헤드리스 스크린샷 테스트
- `node build.mjs` : 오프라인 제출본(dist/) 생성
- `node video.mjs` : 시연영상 캡처/인코딩
